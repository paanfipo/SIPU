# Manual de usuario

## Ingreso al sistema

1. Abrir la URL donde se encuentra instalada la aplicación.
2. Ingresar el correo electrónico y la contraseña del usuario.
3. Seleccionar la opción de inicio de sesión.
4. Verificar que el menú muestre las opciones disponibles según el rol asignado.

## Registro de usuarios

El sistema permite registrar usuarios desde formularios administrativos o desde enlaces públicos configurados para convocatorias. El proceso de registro captura los datos básicos del usuario y crea las credenciales de acceso requeridas por el flujo de trabajo.

## Gestión de convocatorias

El paquete de emprendimiento permite crear y administrar convocatorias. Una convocatoria incluye información general, fechas, etapas asociadas y actividades necesarias para el seguimiento del proceso.

## Etapas

Las etapas representan los momentos del proceso de emprendimiento. Cada convocatoria puede tener etapas asociadas al avance de los participantes. El sistema permite configurar etapas, consultar su estado y controlar el progreso de los participantes.

## Actividades

Las actividades corresponden a sesiones, tareas o eventos asociados a una etapa. El sistema permite crear actividades, asociarlas a etapas y definir la información necesaria para su seguimiento.

## Cronogramas

La asignación de cronogramas permite programar actividades con fecha, hora y responsable. Esta información facilita el seguimiento operativo y la coordinación entre participantes, asesores y administradores.

## Inscripción pública

SIPU permite habilitar enlaces públicos para que emprendedores o participantes se registren en convocatorias. El formulario público captura la información requerida por el proceso y almacena la inscripción en el sistema.

## Registro masivo

Cuando la convocatoria lo requiere, el sistema permite cargar participantes de forma masiva. Esta funcionalidad facilita la incorporación de grupos amplios de usuarios y reduce el registro manual repetitivo.

## Control de asistencia

El control de asistencia registra la participación de usuarios en actividades programadas. La asistencia puede utilizarse como criterio para seguimiento y avance dentro de las etapas de la convocatoria.

## Avance entre etapas

El sistema permite controlar el avance de participantes o convocatorias entre etapas. Este avance se apoya en la configuración de actividades, asistencias, gestiones y reglas definidas por el proceso.

## Asignación de asesores

SIPU permite asociar usuarios responsables o asesores a actividades y procesos de acompañamiento. Esta asignación facilita el seguimiento académico, administrativo o técnico.

## Documentación y novedades

Los usuarios pueden registrar novedades y documentación relacionada con el proceso. Esta información permite mantener trazabilidad de solicitudes, avances, observaciones y soportes asociados a la convocatoria.

## Reportes

El sistema ofrece reportes por convocatoria para consultar información consolidada sobre participantes, etapas, actividades, asistencia y avance.

## Notificaciones

SIPU gestiona notificaciones internas y por correo electrónico para apoyar la comunicación con los usuarios. El envío de correos requiere configurar las variables SMTP en el archivo `.env` del ambiente de ejecución.
