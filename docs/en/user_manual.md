# User Manual

## Accessing the System

1. Open the URL where the application is installed.
2. Enter the user email and password.
3. Select the login option.
4. Verify that the menu displays the options available for the assigned role.

## User Registration

The system allows users to be registered from administrative forms or from public links configured for calls. The registration process captures basic user data and creates the access credentials required by the workflow.

## Call Management

The entrepreneurship package allows administrators to create and manage calls. A call includes general information, dates, associated stages and the activities required for process follow up.

## Stages

Stages represent the moments of the entrepreneurship process. Each call can have stages associated with participant progress. The system allows users to configure stages, review their status and control participant progression.

## Activities

Activities represent sessions, tasks or events associated with a stage. The system allows activities to be created, associated with stages and configured with the information required for monitoring.

## Schedules

Schedule assignment makes it possible to program activities with date, time and responsible person. This information supports operational follow up and coordination among participants, advisors and administrators.

## Public Registration

SIPU can enable public links so entrepreneurs or participants can register for calls. The public form captures the information required by the process and stores the registration in the system.

## Bulk Registration

When required, the system supports bulk participant registration. This functionality helps incorporate larger groups of users and reduces repetitive manual entry.

## Attendance Tracking

Attendance tracking records user participation in scheduled activities. Attendance may be used as a criterion for monitoring and progression through call stages.

## Stage Progression

The system supports progression of participants or calls between stages. Progression is based on configured activities, attendance records, management actions and process rules.

## Advisor Assignment

SIPU supports assigning responsible users or advisors to activities and support processes. This assignment facilitates academic, administrative or technical follow up.

## Documentation and Updates

Users can register updates and documentation associated with the process. This information preserves traceability of requests, progress, observations and supporting evidence.

## Reports

The system provides call reports for consulting consolidated information about participants, stages, activities, attendance and progress.

## Notifications

SIPU manages internal and email notifications to support communication with users. Email delivery requires SMTP variables to be configured in the `.env` file of the execution environment.
